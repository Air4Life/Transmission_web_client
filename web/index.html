Добавить торрент

Сначала выберите файлы. Загрузка начнётся только после подтверждения.

Изменить папку торрента

Если файлы уже перенесены вручную, снимите отметку. Приложение укажет их расположение и запустит проверку. Для многофайлового торрента выберите родительскую папку его каталога.

Выбрать папку на сервере

Откройте нужную папку и нажмите «Выбрать эту папку». Здесь показаны каталоги сервера Ubuntu.

Настройки загрузок

Изменения сохраняются в Transmission без перезапуска. Папка по умолчанию применяется к новым торрентам.
